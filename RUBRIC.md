# Professional Portfolio Rubric — 100 Points

| Category | Points |
|---|---:|
| Main README and professional organization | 15 |
| Early program and explanation | 10 |
| Mid-course program and explanation | 10 |
| BroBank files and presentation | 20 |
| Compilation instructions, testing, and results | 15 |
| Diagram or visualization | 10 |
| Reflection and learning goals | 15 |
| Clean repository and working links | 5 |
| **Total** | **100** |

The Professional Portfolio is 10% of the final course grade. BroBank is included here as evidence of professional presentation and reflection. Its program functionality is graded separately under the Final Project category.
